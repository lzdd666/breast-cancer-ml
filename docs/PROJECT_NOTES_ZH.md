# 乳腺癌分类项目运行与讲解

这个版本把课程项目整理成可以在 GitHub 展示和复现的机器学习研究练习。
主要改进是评估流程、结果记录和程序结构；新增的概率加权集成是否有效，
以 `results/reference/report.md` 中的实测结果为准。

## 从哪里开始

1. 按 README 创建 Python 虚拟环境并安装 `requirements.txt`。
2. 执行 `python -m unittest discover -s tests -v`，检查评估流程。
3. 执行 `python -m wdbc_ml --quick --output results/smoke`，确认完整程序能够运行。
4. 执行 `python -m wdbc_ml --output results/my-run`，得到完整实验。
5. 打开输出目录中的 `report.md`，对照 CSV 和 JSON 查看每个数值的来源。

不需要单独下载数据。数据随 scikit-learn 提供，共 569 个样本、30 个特征，
其中恶性 212 个、良性 357 个。本项目统一设置恶性为正类 1。

## 需要掌握的评估逻辑

外层五折用于评分：每次留出一折，其余四折用于训练。内层三折只在外层训练
数据中划分，用于选参数、选择单模型类别和选择投票权重。标准化放在 Pipeline
里，因此每次拟合时只接触当前训练部分。

所有模型使用相同的外层划分。`selected_single` 是每一折里由内层 AUC 选出的
单模型，可能在不同折中选到不同算法。比较集成与它的差值，可以避免先看外层
结果、再挑一个最方便的对照模型。五折之间训练数据有重叠，因此这里报告描述性
差异，没有把五个分数当成五次独立实验做显著性结论。

概率加权集成的成员是逻辑回归、SVM 和随机森林。内层比较四组固定候选权重；
成员本身采用预先规定的参数，不把外层测试成绩用于调权重。它和五种单模型的
参数搜索是不同的实验分支。两者都保存了各自的候选设置，方便解释比较范围。

异常值分析使用 IQR 规则识别异常数值，仅计数和输出，不删除或替换样本。
聚类、标准化和 PCA 属于全数据探索，结果不会作为额外特征反馈进分类模型。

## 结果文件怎么读

| 文件 | 回答的问题 |
| --- | --- |
| `summary.csv` | 各模型的外层平均成绩和标准差是多少？ |
| `fold_metrics.csv` | 每一折的 accuracy、AUC、F1、recall 等是多少？ |
| `paired_differences.csv` | 同一折上，集成比内层选出的单模型高还是低？ |
| `searches.json` | 每一折比较了哪些参数，最终选了什么？ |
| `splits.json` | 哪些样本用于训练、内层验证和外层评分？ |
| `predictions.csv` | 每个样本在哪一折获得了怎样的恶性概率？ |
| `feature_importance_summary.csv` | 随机森林特征重要性和置换重要性有什么区别？ |
| `clustering.csv` | 聚类内部指标、噪声比例和覆盖率是多少？ |
| `metadata.json` | 使用了什么环境、随机种子和代码版本？ |

F1、召回率和精确率都指恶性类别；accuracy 指全部样本。
CSV 中的指标使用 0 到 1 的数值，写成百分比时需要乘以 100。
标准差反映这些外层折之间的变化，不是置信区间。
置换重要性衡量打乱某个特征后 AUC 的变化，不能直接解释为生物学因果作用。
